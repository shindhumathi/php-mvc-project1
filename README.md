PHP MVC Mini Project

A simple PHP MVC (Model-View-Controller) application developed using Object-Oriented Programming concepts and Composer autoloading.

Technologies Used

PHP, MySQL, Object-Oriented Programming (OOP), Composer, MVC Architecture, MySQLi, Git & GitHub

This project follows the MVC design pattern:

Model: Handles data-related operations and database interactions.
View: Responsible for presenting application data.
Controller: Handles application requests and coordinates between models and views.
